# API do projeto DidatiKids

## Requisitos
- Python 3
- Django
- Django Rest Framework
- psycopg2

## Execução manual
Para executar o projeto, crie um ambiente virtual com o comando `python -m venv [nome_do_ambiente]`.
Ative o ambiente pelo cmd com o comando `call [nome_do_ambiente]/Scripts/activate`, ou use `source venv/bin/activate` na bash.
Instale os pacotes listados utilizando o comando `pip install -r requirements.txt`.
Após instalar os pacotes necessários, listados no [./requirements.txt](arquivo de requisitos), execute `python manage.py runserver` para iniciar o servidor.

## Execução automatizada
Execute o comando `call run.bat` dentro do Command Prompt para iniciar o servidor.
